# 스케일 학습 트레이너 — 시스템 정의서

## 0. 한 줄 요약
좋아하는 곡(YouTube 링크) 위에서, 그 곡의 코드에 맞는 스케일을 가이드/연습 모드로 익히는 데스크톱 앱. 연습 모드에서는 ML이 생성한 자연스러운 리프를 곡에 맞춰 들으며 따라 칠 수 있다. 사용자의 연주(MIDI·화면 건반)는 실시간 판정되고, 진행 1주기(패스)마다 채점 요약으로 피드백된다. 양손 연주는 스플릿 포인트로 왼손(반주)/오른손(솔로)을 나눠 평가한다.

## 1. 목표 & 타겟
- **타겟**: 양손으로 곡은 치지만 즉흥은 못 하는 중급자
- **문제**: 이론(스케일·코드) 지식과 실시간 적용 사이의 갭
- **해결**: 실제 곡 위에서 "언제 어떤 스케일이 통하는지"를 직접 쳐보며 학습
- **의의**: AI 생성 시대에, AI로 인간의 즉흥 능력을 증강(대체 아님). 기존 앱이 비운 "중급→즉흥" 구간

## 2. 핵심 흐름
링크 입력 → 코드+키 감지 → 가능한 스케일 탐색 → (선택지 있으면 집중 스케일 선택 / 없으면 바로) → 세션 미리 굽기 → 재생·연습(+필요 시 분석 결과 보정) → **[학습 루프] 진행 1주기 반복 → 패스 채점(존별) → 요약 → (원하면) 난이도 단계 변경**

## 3. 스케일 탐색 (자동, 음악 이론)
- **키 감지**: MIR 도구 제공값, 없으면 폴백(코드들의 다이아토닉 적합도 최대 키)
- **scale_db 필수 포함 — 7 다이아토닉 모드**:
  이오니안(Maj7·메이저 트라이어드) / 도리안(m7) / 프리지안(m7) / 리디안(Maj7#11) / **믹솔리디안(도미넌트 7th)** / 에올리안(m·m7) / 로크리안(m7b5)
- **코드별 스케일 배정**
  - 다이아토닉 → 키의 해당 모드 (예: C장조 Dm7→D도리안, G7→G믹솔리디안, Cmaj7→C아이오니안. 같은 7음, 시작점만 다름)
  - 비다이아토닉(고립) → 그 코드 품질의 코드-스케일(로컬 디투어) 후 홈 복귀
  - 전조 → 새 키 2개 이상 연속 일관 시 키 전환(루프 단위 재평가)
- **집계**: 곡 전체 등장 스케일 종류를 모아 사용자에게 제시
- **선택(옵션)**: 연습 모드에서 집중할 스케일 고르기. 안 고르면 모든 스케일에서 리프 재생

## 3.5 사용자 보정 (분석 초안 원칙)
- **원칙**: 자동 분석(MIR)은 **초안**이다. 사용자가 Score 화면에서 간단한 개입으로 보정하며, 보정 시 MIR 재실행 없이 **구조 재계산만** 수행한다(§4 "재분석 없음" 원칙 유지).
- **보정 항목 (1차)**:
  - **코드**: 마디 클릭 → 코드 수정 (구현됨)
  - **루프 주기**: 감지값 override — 1/2/4/8/16마디 중 선택
  - ~~스플릿 포인트~~: 양손 존 경계는 **C3 고정**(설정 제거 — 휴리스틱으로 충분)
- **보정 항목 (2차)**: **마디선** — 다운비트 한 박 밀기/당기기 + 3/4↔4/4 전환 (세그먼트 재격자화 필요, 가장 침습적)

## 4. 아키텍처 — 빌드 → 플레이어
- "분석 중" 화면에서 세션 타임라인 **미리 굽기**(코드/키/스케일/ML 예시 전부 사전 계산)
- 메인 = 플레이어. 스크럽 = 인덱스 점프. 재분석/재추론 없음
- ML은 빌드 시 1회만(예시 생성)

## 5. 타임라인 스키마
```
global: { audio_ref, bpm, time_sig, key, content_span:[s,e], available_scales:[...],
          scale_riffs: { "D 도리안": [{interval, beat_pos}...], ... } }  # 스케일 종류당 1개, 상대값
segments: [
  { idx, start_sec, end_sec, start_bar, end_bar,
    chord: { name, root, quality, degree },     # degree 예: "ii"
    scale: { name, note_set:[pc...] } }          # 예: "D 도리안"
]
```

## 6. 화면 & UI
- **[0] 링크 입력** (+ 첫 실행 온보딩 카드) + **라이브러리**: 저장 폴더의 세션(.json)을 카드로 나열 — 클릭 한 번으로 재분석 없이 재개
- **[1] 분석 중**: 단계 체크리스트(오디오 가져오기 → 비트·코드 인식 → 구조·화성 분석 → 세션 굽기) + 진행바. **연습하며 기다리기** — 분석은 백그라운드로 계속, 링크 화면(세션 열기만 활성)으로 복귀 + 상단 알약에 "분석 중… N%" → 완료 시 **연주하기** 버튼(그 곡의 박자 조정 화면으로)
- **[2a] 박자 조정**: **마스터-디테일** — 좌측 고정(처음/마지막 10초 확대바·박자·BPM·확정·조정완료, 드래그=격자 평행이동, BPM은 입력만) / 우측 코드표만 스크롤. **확정 = 편집부 잠금(불투명, 버튼이 '수정'으로 토글)**. 코드표 직접 조작: **칸 클릭=코드 수정, 칸 드래그=루프 지정**(놓으면 이름 입력, 시작 칸 복귀=1마디 루프) — 표 상단에서 루프 리스트 관리(삭제)
- **[2] 스케일 확인**: **곡맥락 리스트**(스케일 종류별 행 — 사용 코드·마디 범위) + 선택 스케일의 **피아노롤**(좌측 세로 건반 거터가 C 기준 스케일 가이드 겸용, 음높이 레인에 리프 노트) + **리프 재생성**(변주 시드)·리프 듣기. 보정·루프는 모두 박자 조정 화면
- **[3] 메인 플레이어** (C안 코드 레인 — 상단=시간, 중간=공간, 하단=컨트롤)
  - **코드 레인(상단)**: 스크럽+HUD+다음 미리보기 통합 — **고정 플레이헤드**(폭 34%)로 코드 블록이 흘러들어옴. 지난 블록 dim / 현재 블록 강조(코드명·스케일 종류) / **바로 다음 블록엔 미니 건반 미리보기 내장**. 비다이아토닉 경계 빨강, 켜진 루프 스팬 하이라이트. **레인 드래그=시킹, 블록 클릭=그 구간 시작으로 점프**
  - **피아노 키보드(C3–B6)**: 스케일 가이드 — 코드톤 진함 / 스케일음 연함 / 스케일 밖 경고색 / 기능 라벨. **스플릿 포인트(C3 고정)로 왼손(반주)/오른손(솔로) 존 구분**. 건반 중앙(B4|C5)에 시각 간격으로 두 손 영역 분리. 친 음 = 호박색
  - **리프 뷰**: 리프연습 시 레인 바로 아래 밴드로 표시
  - **패스 요약 카드**: 패스 경계에서 수 초 표시(오른손 스케일 적중률·왼손 코드톤 적중률·코드톤 착지·최다 스케일 밖 음) 후 소멸
  - **하단 컨트롤 한 줄**: 리프연습 토글(가이드 ↔ 연습) · 난이도 선택기(없음/Lv1/Lv2/Lv3) · **루프 버튼 = 사이드바**(루프별 ON/OFF — 켜진 루프 끝에 닿으면 시작으로 반복) · 실시간 적중률 배지 · 카운트인 · 재생/일시정지. 상단바에 시간(mm:ss/mm:ss)

## 7. 모드
- **가이드**: 스케일 전체 + 기능 라벨 풀 표시
- **연습**: 현재 코드 근음으로 이조된 ML 리프가 곡에 맞춰 반복 재생. 사용자가 보고 듣고 따라 칠 수 있음
- 채점은 **상시** 동작하되, **채점 기준은 모드를 따라간다**:
  - **가이드 모드**: 존별 채점(왼손 코드톤/오른손 스케일) + 난이도 Lv1~3 적용
  - **리프연습 모드**: 학습 목표가 '생성된 리프 따라치기'이므로 **리프 일치도만** 채점(2차). 난이도 미적용(선택기 비활성)
- **모드와 난이도는 직교**: 모드는 '무엇을 배울까'(스스로 적용 vs 리프 따라치기)의 축, 난이도는 가이드 모드 안의 '채점 기준' 축. 레벨에 따른 모드 전환 없음
- **가이드 배지는 난이도 기준을 따라감**: 난이도 선택 시 존별 목표음만 배지 표시(예: Lv1 = 왼손 존 근음·오른손 존 코드톤만, 비목표음은 흐리게)

## 7.5 연주 채점 (학습 루프)
- **판정 단위**: note-on 이벤트(길이 무시). 입력: MIDI + 화면 건반
- **존 구분**(가이드 모드): 스플릿 포인트 미만 = 왼손(반주) 존 → **코드톤 판정** / 이상 = 오른손(솔로) 존 → **스케일 판정**. 화면 건반(마우스 단선 입력)은 오른손 존으로 간주 — 양손 평가는 MIDI 건반 전제
- **스케일 적중**: 친 음의 pc ∈ 현재 구간 note_set
- **코드톤 착지**: 마디 첫박 ±허용창(≈0.25박) 내 note-on의 pc ∈ 코드톤
- **리프 일치도**(리프연습 모드, **2차**): 리프의 각 음(시각·음높이)에 ±타이밍 허용창 내 note-on이 맞으면 적중 → 일치율 %. 1차에서 리프연습 모드는 채점 없음(따라치기 자체가 자기평가 내장 — 채점은 가이드 모드에 집중)
- **패스**: content 구간 내 감지된 루프(loop_len 마디, 사용자 override 반영) 1주기. 루프 미검출·미보정 시 곡 전체 = 1패스
- **패스 요약**(모드별): 가이드 = 존별 적중률 %·코드톤 착지 수/기회·최다 스케일 밖 음 / 리프연습(2차) = 리프 일치율 %
- **패스 간 추이(세션 내, 1차)**: 최근 패스 적중률 나열(예: "62→75→81%") — 향상이 보이는 것이 학습 동기의 핵심. 세션 종료 시 소멸(영속화는 §10 제외)
- **난이도(가이드 모드 선택·양손 커리큘럼)** — 존별 채점 기준이 레벨에 따라 달라짐:
  - **Lv1: 왼손 근음 + 오른손 코드톤**
  - **Lv2: 왼손 근음 + 오른손 스케일**
  - **Lv3: 왼손 코드톤 + 오른손 스케일** (= 상시 채점 기본 기준과 동일)
  - 채점 기준 필터일 뿐 **통과·실패·잠금 없음**. 반복 연습은 사용자 정의 루프(§6 사이드바)로 수행
  - 양손 난이도는 MIDI 건반 전제(화면 건반은 오른손 존만 판정)
- **UI 언어 원칙**: 스케일 밖 음은 "틀림"이 아니라 **"스케일 밖"** 중립 표현(아웃 노트는 즉흥의 합법 어휘)

## 8. ML — 자연스러운 스케일 리프 생성 (졸업작품 기술 핵심)
- 조건부 시퀀스 모델 1개: (코드 quality + 스케일 종류) → 자연스러운 단성 리프
- **화성 상대값 표현**(키 독립), 자기지도 다음음 예측, Weimar Jazz DB·Lakh MIDI 단성 멜로디 학습
- 학습은 오프라인(Colab), 앱은 가중치 로드 → 빌드 시 **스케일 종류당 1회 생성(상대값 저장)**
- 재생 시 현재 segment의 코드 근음으로 이조해 출력
- **구조 생성기**(모델은 도수 사전분포로 개입): 박 단위 리듬 셀(정박 위주) → 마디 앞 절반 모티프를 뒤 절반에 반복(**AA′** — 외워 써먹는 리프 구조) + 컨투어 목표선(아치/상행/하행/웨이브) + 스텝모션 + 정박 코드톤 앵커 + 마지막 음 코드톤 해결
- 로봇식 음계 ❌ / 음악적 라인 ✅
- 리프는 **오른손(솔로) 예시 전용**(단성 멜로디 라인). 왼손(반주)은 규칙 기반 코드톤 판정만 사용하며 ML 무관

## 10. 스코프
**포함 (1차 = MVP)**: 링크 입력, 코드/키/스케일 자동 분석, 코드 HUD(현재+다음+도수), 스케일 가이드/연습 모드, MIDI 입력(스플릿 기반 왼/오 존 구분), ML 리프(스케일 종류당 1개) 생성·연습 모드 재생, 스크럽, **가이드 모드 존별 채점(상시) + 난이도 Lv1~3, 패스 요약 + 패스 간 추이(세션 내), 루프 주기 보정(스플릿은 C3 고정), 사용자 정의 루프(마디 선택 정의 + 루프별 ON/OFF)**

**포함 (2차)**: 리프 일치도 채점, 마디선/박자 보정, 배지 필터 고도화

**제외**: 곡 선곡용 난이도 등급(연습 난이도 Lv와 무관), 장르/스타일 선택, 진행 패턴 이름(ii-V-I 네이밍), 퀴즈 모드(블러 해제), 녹음·저장, 연습 기록 영속화(세션 간 진척 저장), 자동 손 분리(ML 핸드 트래킹 — 스플릿 휴리스틱으로 충분), 콜앤리스폰스(구간 분리형 듣고-따라하기 — 리프 일치도 채점과는 다른 기능)
