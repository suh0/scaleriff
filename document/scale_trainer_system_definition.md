# 스케일 학습 트레이너 — 시스템 정의서

## 0. 한 줄 요약
좋아하는 곡(YouTube 링크) 위에서, 그 곡의 코드에 맞는 스케일을 가이드/퀴즈로 연습하고, ML이 생성한 자연스러운 스케일 연주 예시를 듣거나 같이 치며 익히는 데스크톱 앱.

## 1. 목표 & 타겟
- **타겟**: 양손으로 곡은 치지만 즉흥은 못 하는 중급자
- **문제**: 이론(스케일·코드) 지식과 실시간 적용 사이의 갭
- **해결**: 실제 곡 위에서 "언제 어떤 스케일이 통하는지"를 직접 쳐보며 학습
- **의의**: AI 생성 시대에, AI로 인간의 즉흥 능력을 증강(대체 아님). 기존 앱이 비운 "중급→즉흥" 구간

## 2. 핵심 흐름
링크 입력 → 코드+키 감지 → 가능한 스케일 탐색 → (선택지 있으면 집중 스케일 선택 / 없으면 바로) → 세션 미리 굽기 → 재생·연습

## 3. 스케일 탐색 (자동, 음악 이론)
- **키 감지**: MIR 도구 제공값, 없으면 폴백(코드들의 다이아토닉 적합도 최대 키)
- **코드별 스케일 배정**
  - 다이아토닉 → 키의 해당 모드 (예: C장조 Dm7→D도리안, G7→G믹솔리디안, Cmaj7→C아이오니안. 같은 7음, 시작점만 다름)
  - 비다이아토닉(고립) → 그 코드 품질의 코드-스케일(로컬 디투어) 후 홈 복귀
  - 전조 → 새 키 2개 이상 연속 일관 시 키 전환(루프 단위 재평가)
- **집계**: 곡 전체 등장 스케일 종류를 모아 사용자에게 제시
- **선택(옵션)**: 집중할 스케일 고르기. 안 고르면 전부 가이드

## 4. 아키텍처 — 빌드 → 플레이어
- "분석 중" 화면에서 세션 타임라인 **미리 굽기**(코드/키/스케일/ML 예시 전부 사전 계산)
- 메인 = 플레이어. 스크럽 = 인덱스 점프. 재분석/재추론 없음
- ML은 빌드 시 1회만(예시 생성)

## 5. 타임라인 스키마
```
global: { audio_ref, bpm, time_sig, key, content_span:[s,e], available_scales:[...] }
segments: [
  { idx, start_sec, end_sec, start_bar, end_bar,
    chord: { name, root, quality, degree },     # degree 예: "ii"
    scale: { name, note_set:[pc...] },           # 예: "D 도리안"
    example_phrase: [ { midi, beat_pos } ] }     # ML 생성 자연 연주 예시
]
```

## 6. 화면 & UI
- **[0] 링크 입력** (+ 첫 실행 온보딩 카드)
- **[1] 분석 중** (스케일 탐색·예시 생성 진행)
- **[2] 스케일 선택** (선택지 있을 때만)
- **[3] 메인 플레이어**
  - **코드 HUD(상단)**: 현재 코드+스케일명+도수, 다음 코드 미리보기(일반 모드면 다음 스케일도 흐리게)
  - **피아노 키보드(C2–B5)**: 스케일 가이드 — 코드톤 진함 / 스케일음 연함 / 스케일 밖 경고색 / 기능 라벨. **손 구분 없음**(어느 손으로 치든 동일 인식). 친 음 = 호박색
  - **모드 토글**: 가이드 ↔ 퀴즈
  - **ML 예시**: 듣기 / 같이 연주 버튼
  - **스크럽 바**: 코드 변경 눈금 + 헤드, 드래그=즉시 seek
  - **하단**: 재생/일시정지

## 7. 모드
- **가이드**: 스케일 전체 + 기능 라벨 풀 표시
- **퀴즈**: 전부 가려짐 → 친 건반만 블러 해제(코드톤/스케일음/밖 상태 표시) → **코드 바뀌면 전체 리셋**

## 8. ML — 자연스러운 스케일 연주 예시 (졸업작품 기술 핵심)
- 조건부 시퀀스 모델 1개: (코드 root+quality + 스케일) → 자연스러운 단성 프레이즈
- **화성 상대값 표현**(키 독립), 자기지도 다음음 예측, Weimar Jazz DB·Lakh MIDI 단성 멜로디 학습
- 학습은 오프라인(Colab), 앱은 가중치 로드 → 빌드 시 segment마다 예시 생성·저장
- 로봇식 음계 ❌ / 음악적 라인 ✅

## 9. (선택) Claude API 설명 코치
- "왜?" 버튼 → 현재 코드·스케일 관계를 자연어로 설명(학습 보조). 확장 포인트

## 10. 스코프
**포함**: 링크 입력, 코드/키/스케일 자동 분석, 코드 HUD(현재+다음+도수), 스케일 가이드/퀴즈, MIDI 입력(손 구분 없음), ML 예시 생성·재생·같이 연주, 스크럽
**제외**: 난이도 티어, 장르/스타일 선택, 진행 패턴 이름(ii-V-I 네이밍), 연주 분석·채점, 녹음·저장, 콜앤리스폰스, 빠른 곡 특수처리

## 11. 기술 스택
Python 3.11 · PyQt6 · yt-dlp · madmom/Essentia/librosa(코드·키·BPM·다운비트) · QtMultimedia(재생) · mido(MIDI 입력) · PyTorch(ML, 오프라인 학습/앱은 로드) · (선택)Claude API

## 12. 기존 프로젝트 재활용
`piano-scale-trainer` 직접 재사용: `scale_db`, `scale_matcher`, `chord_function_analyzer`, 피아노 위젯. MIR 파이프라인·키보드 UI는 즉흥 트레이너 설계분에서 이어받음.
